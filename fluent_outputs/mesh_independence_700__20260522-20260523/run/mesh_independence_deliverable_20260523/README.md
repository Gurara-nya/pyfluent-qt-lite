# Mesh Independence Deliverable, 2026-05-23

本文件夹整理了本轮 D40 fuel-wall 网格无关性验证的主要输出，包括最终图、原始表格、分析脚本、运行记录索引和总结报告。

## 文件夹结构

- `REPORT_mesh_independence_summary.md`
  含图总结报告，包含最终对比图、前端局部燃速图、异常点处理说明和下一步计划。
- `figures/core/`
  最终报告使用的关键图片。默认采用“排除异常点，并叠加 040-fw2400/040-fw3200 rerun”的版本。
- `figures/appendix/`
  附录图，包括早期 clean 图、全量含异常图、端部剖面图等。
- `tables/`
  解析后的 CSV/JSON 表格，包括最终汇总表、原始 fuel-wall profile 点、端部指标和收敛误差。
- `scripts/`
  当前使用的分析脚本快照。
- `run_records/`
  原始 batch manifest/state，以及 `source_data_index.csv`。该索引列出了每个 dat/cas 的原始路径、是否进入最终图、排除原因和关键指标。

## 核心表格

- `tables/mesh_independence_metrics_nonabnormal_with_supplemental_rerun040.csv`
  最终主表，包含 12 个正常 sweep 点、2 个 nofuel 补充点、2 个 fuelend040 rerun 点。
- `tables/mesh_independence_metrics_all_with_supplemental.csv`
  包含异常点和补充点的全量解析表。
- `run_records/source_data_index.csv`
  原始 HDF5 数据索引。为避免重复复制近 GB 级的 dat/cas 文件，本交付包默认保留 HDF5 原路径，而不是复制 dat 本体。

## 数据处理口径

- 燃速来自 cell UDM 的 `udm_r_total`，单位换算为 `mm/s`。
- fuel-wall 表面温度来自 `udm_Tsurf`，并用 `SV_WALL_T_INNER` 做边界壁温对照。
- fuel-wall 区域通过 case HDF5 的 `fuel-wall` face zone 与 cell UDM 的 `udm_FuelWallFlag` 识别。
- 面积加权使用 `udm_FaceArea`。
- 异常点剔除标准：continuity final residual 达到 `1e5` 量级，且燃速约 `0.001146 mm/s`、Tsurf 约 `565 K`。

## 结论速览

- 本轮原始 15 个 700 步 sweep dat 中，12 个通过物理验收，3 个异常点不纳入最终 clean 图。
- 异常点为 `fuelend040-fw1600-flowopt`、`fuelend080-fw2400-flowopt`、`fuelend120-fw3200-flowopt`。
- 新增 nofuel 补充点均能正常解析：
  `nofuel-standard` 为 600 步，燃速约 `1.6304 mm/s`；
  `nofuel-flowsoft-lr` 为 400 步，燃速约 `1.6758 mm/s`。
- `fuelend040-fw2400` 和 `fuelend040-fw3200` 已重新运行 700 步，结果与原正常 dat 一致，作为图中的 rerun 星形标记。

## 下一步计划

下一步不再采用当前这类 fuelend 方向或局部加密方案作为主路线。建议使用 `nofuel` 或 `fuelend040` 版本作为基准几何/基准网格，只修改 `fuel-wall face count`，围绕 fw 面数做更干净的一维网格无关性验证。这样变量更少，结果解释更直接，也更适合判断燃速和 fuelwall 壁温对壁面离散数量的敏感性。
